## Corte recomendado para iniciar desarrollo

Para empezar a codificar sin esperar toda la validacion, el corte minimo razonable es:

- E2-02 Disenar mini pagina publica.
- E2-03 Definir sistema visual.
- E3-01 Crear base del proyecto.
- E3-02 Configurar framework web.
- E3-03 Configurar base de datos.
- E4-01 Desarrollar landing publica.
- E5-01 a E5-03 Panel basico de negocios.
- E6-01 a E6-05 Mini pagina publica esencial.
- E7-01 y E7-02 QR y link.
